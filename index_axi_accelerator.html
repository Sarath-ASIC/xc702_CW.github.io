Protocol and register map

Newline-terminated ASCII. GUI → firmware: PING, HELP, STATUS, SET_A a00 a01 a10 a11, SET_B b00 b01 b10 b11, RUN, READ. Firmware → GUI: OK PONG | OK HELP … | OK STATUS BUSY=x DONE=x | OK A | OK B | OK STARTED | EVENT DONE | OK C c00 c01 c10 c11 | ERR msg.
